# Data

This folder is reserved for public derived Arctic sea ice NetCDF files used by the notebook. Raw NetCDF files are ignored by Git and should be downloaded separately.

Data source: [Jahn and Heuze (2024), Arctic Data Center](https://doi.org/10.18739/A2CC0TV9V).

Expected local layout:

```text
data/
|-- CMIP6_historical_data/
|-- CMIP6_ssp_data/
```
